# e2e

Playwright suites: workspace, portal, and the blocking tenancy suite.

The critical-flow list (Governance §15.3): practice signup + client intake · client onboarding via SMS OTP · ingest across channels to Ready · **chase → portal upload with editable overlay → auto-close** · Review → Approve on rule-activate, chase-send and bulk publish, with **Approve asserted unreachable before Read-review** · publish to the Xero sandbox with attachment · Rejected/Failed view + retry · entity move with addressee warning · export and data-subject export/erasure.

The tenancy suite attempts real cross-practice, cross-client and delegated-session-overreach access with real tokens. **All must fail.** It runs on every merge and it blocks.

Runs locally during bootstrap; enters CI at Infra Week (G1/G8).
